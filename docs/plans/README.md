# Plans

Execution plans for multi-step work, checked in so any session can pick up
where the last one stopped.

- `active/`: in progress. Update **Progress** and **Decision log** as you go.
- `completed/`: moved here when done, unchanged otherwise.

Small changes don't need a plan. Anything spanning several sessions does.

Template:

```markdown
# <goal>

Goal: one paragraph, what "done" looks like and how it is verified.

## Steps
- [ ] ...

## Progress
<date>: what happened.

## Decision log
<date>: decision, and why.
```
